# متغیرهای محیطی

تمام متغیرهای محیطی برای بک‌اند Django و RAG:

## متغیرهای RAG (اختیاری — پیش‌فرض‌ها معقول است)

### مدل امبدینگ و کارایی

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `RAG_EMBED_MODEL` | `bge-m3` | مدل امبدینگ: `bge-m3` (بهترین کیفیت)، `e5-base` (سریع‌تر)، یا `minilm` (سبک) |
| `RAG_EMBED_FP16` | `1` | استفاده از `float16` روی Apple Silicon (سریع‌تر و کم‌حافظه‌تر) |
| `RAG_PARTS_CSV` | (خودکار) | مسیر فایل CSV واژه‌نامه‌ی فارسی↔انگلیسی (پیش‌فرض: `Book1.csv` در ریشه پروژه) |

### بازیابی و رتبه‌بندی

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `RAG_GROUND_SIM_FLOOR` | `0.55` | آستانه‌ی کمینه‌ی شباهت برای پذیرش جواب (کمتر = جوابات بیشتر اما کم‌دقت) |
| `RAG_CACHE_TTL` | `900` | مدت زمان کش کردن پاسخ‌ها (ثانیه؛ ۱۵ دقیقه پیش‌فرض) |
| `RAG_CACHE_MAX` | `512` | حداکثر تعداد جوابات کش‌شده در حافظه |
| `RAG_RERANK` | `0` | استفاده از مدل reranker (دقیق‌تر اما سنگین‌تر): `1` یا `0` |
| `RAG_RERANK_MODEL` | `BAAI/bge-reranker-v2-m3` | مدل reranker (فقط اگر `RAG_RERANK=1`) |

### سمنتیک کش

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `RAG_SEM_CACHE` | `1` | فعال کردن کش‌ی سمنتیک (پاسخ‌های یکسان/شبیه): `1` یا `0` |
| `RAG_SEM_CACHE_SIM` | `0.95` | آستانه‌ی شباهت برای کش‌ی سمنتیک (بالاتر = تنها duplicate دقیق) |

### بازخورد کاربر (Feedback loop)

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `RAG_FEEDBACK_BOOST` | `1` | اعمال رتبه‌بندی بر اساس کلیک‌های کاربر: `1` یا `0` |
| `RAG_FB_CACHE_TTL` | `300` | مدت نگه‌داری نقشه‌ی boost در حافظه (ثانیه؛ ۵ دقیقه پیش‌فرض) |
| `RAG_LOG_QUERIES` | `1` | ثبت تمام پرسش‌ها در `feedback.db`: `1` یا `0` |

### تشخیص عیب (Diagnostic engine)

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `RAG_DIAG_CACHE_TTL` | `900` | کش نتایج تشخیص (ثانیه؛ ۱۵ دقیقه پیش‌فرض) |

## متغیرهای Django (اختیاری — پیش‌فرض برای توسعه)

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `DEBUG` | `True` | حالت debug (تغییر به `False` برای production) |
| `ALLOWED_HOSTS` | `127.0.0.1,localhost` | میزبان‌های مجاز |
| `SECRET_KEY` | (سخت‌کدشده) | کلید امنیتی Django (باید به محیط منتقل شود) |

## متغیرهای فرانت‌اند (Next.js)

فایل `kg_frontend/.env.local`:

| متغیر | مقدار پیش‌فرض | توضیح |
|-------|-------------|-------|
| `METIS_API_KEY` | (اجباری) | کلید API دستیار Metis |
| `METIS_BOT_ID` | (اجباری) | شناسه bot در Metis |
| `BACKEND_URL` | `http://127.0.0.1:8000` | آدرس بک‌اند Django |

## تنظیمات Offline

برای اجرای مکمل بدون دانلود model‌ها (نیاز به دانلود قبلی):

```bash
export HF_HUB_OFFLINE=1
export TRANSFORMERS_OFFLINE=1
./run_rag_build.sh
```

## مثال‌های استفاده

### ساخت RAG با e5-base (سریع‌تر):
```bash
export RAG_EMBED_MODEL=e5-base
./run_rag_build.sh
```

### غیرفعال کردن کش برای آزمایش:
```bash
export RAG_CACHE_TTL=0
export RAG_SEM_CACHE=0
./run_server.sh
```

### تنظیم آستانه‌ی grounding سخت‌گیرانه:
```bash
export RAG_GROUND_SIM_FLOOR=0.65
./run_server.sh
```

## مدل‌های امبدینگ

هر مدل trade-off متفاوتی دارد:

| مدل | بعد | حافظه | سرعت | کیفیت | موارد استفاده |
|-----|-----|-------|------|-------|--------------|
| **bge-m3** | 1024 | ~2.3GB | بطیء | بهترین | production (اگر منابع کافی) |
| **e5-base** | 768 | ~1.1GB | متوسط | خوب | تعادل کیفیت/سرعت |
| **minilm** | 384 | ~0.5GB | سریع | قابل‌قبول | محدود منابع / لپ‌تاپ |

**نکته:** مدل امبدینگ باید هنگام **ساخت** و **سرو** یکسان باشد.
