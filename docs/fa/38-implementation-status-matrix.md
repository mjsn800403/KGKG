# ۳۸ — ماتریس وضعیت پیاده‌سازی و بهره‌برداری (آنچه امروز واقعاً وجود دارد)

هدف: یک مرجع واحد برای پاسخ به این پرسش که «سامانه واقعاً چه دارد و چه ادعاهایی را می‌توان مشروعاً مطرح کرد؟» در گزارش‌های رسمی و ارزیابی بیرونی.
در هر ردیف، **کد**، **استقرار**، **پیکربندی**، **شواهد بهره‌برداری**، **آزمون‌ها** و **مشاهدهٔ مستقیم روی سرور تولید** از هم تفکیک شده‌اند.
نسخهٔ انگلیسی: [../38-implementation-status-matrix.md](../38-implementation-status-matrix.md). عبارت‌بندی آمادهٔ گزارش برای هر زیرسامانه: [39](39-evaluation-evidence-guide.md).
